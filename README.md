A make.fun entry for [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee?ref=h379tqrk).

`main.py` writes one pickup line, spoken by a vending machine to a passing human, to `entry.txt` — a coil that has held a chocolate bar hostage since Tuesday, suddenly wanting to let it drop for the passer-by. The line is 111 characters, well under the 200-character cap, and deterministic: the same line on every run.
